# Измерение скорости скачивания

`speedtest.js` десять раз подряд скачивает файл по прямой HTTP- или HTTPS-ссылке. Следующий запрос начинается после полного чтения предыдущего ответа. Скрипт получает данные порциями и складывает их размеры.

## Запуск

Требуется Node.js 22 или новее. Скрипт использует только встроенные модули. Из каталога проекта выполните команду, подставив прямую ссылку на файл. Кавычки позволяют передать URL с параметрами.

```bash
node speedtest.js "https://example.org/path/to/file.jpg"
```

По умолчанию на каждый запрос отводится 120 секунд с момента отправки до конца загрузки, включая подключение и ожидание ответа. Чтобы изменить этот лимит, передайте целое число секунд через `--timeout`. Например, для скачивания большого файла можно отвести пять минут на каждую из десяти попыток.

```bash
node speedtest.js --timeout 300 "https://example.org/path/to/file.jpg"
```

Отдельно действует тайм-аут бездействия в 30 секунд. Если установленное соединение простаивает столько времени, запрос завершится досрочно. Если сервер продолжает присылать данные по чуть-чуть, сработает общий лимит запроса.

### Проверка на своём компьютере

В одном терминале запустите сервер, который отправляет ровно 1 000 000 байт в каждом ответе.

```bash
node -e "const data = Buffer.alloc(1000000); require('node:http').createServer((req, res) => res.end(data)).listen(8000, '127.0.0.1')"
```

Во втором терминале из каталога проекта запустите замер.

```bash
node speedtest.js "http://127.0.0.1:8000/"
```

Ожидаемый итог — 10 запросов и 10 000 000 байт. Чтобы остановить сервер, нажмите Ctrl+C в первом терминале. Для замера через интернет укажите ссылку на файл на удалённом сервере.

## Как читать результат

- **Среднее время запроса, с** — сумма длительностей десяти запросов, делённая на десять. Каждый замер начинается перед установкой соединения и заканчивается после чтения всего тела ответа.
- **Всего скачано, байт** — сумма размеров прочитанных тел ответов. HTTP-заголовки в объём не входят.
- **Скорость скачивания, Мбит/с** — общий объём в байтах × 8 / суммарное время в секундах / 1 000 000. Результат характеризует загрузку с выбранного сервера, включая время соединения и ожидания ответа.

При скачивании маленькой картинки установка соединения и ожидание первого байта могут занять большую часть замера. Для оценки скорости передачи выберите файл, загрузка которого длится хотя бы несколько секунд. Учитывайте расход трафика — скрипт скачивает файл десять раз.

Если все десять ответов пустые, скрипт показывает число запросов, среднее время и нулевой объём. Вместо числовой скорости он сообщает, что измерение не удалось, и завершается с кодом 1. Если пустой только один из ответов, в расчёт входят фактические байты и время всех десяти запросов.

При перенаправлении укажите конечный URL файла. При сетевой ошибке, ошибке HTTP, обнаруженном обрыве или превышении тайм-аута скрипт сообщает номер запроса и завершается с кодом 1. Итог выводится только после десяти успешных загрузок.

## Автоматические тесты

Запустите тесты из каталога проекта.

```bash
node --test
```

Тесты запускают скрипт через командную строку и используют локальный HTTP-сервер. Доступ в интернет не требуется.
